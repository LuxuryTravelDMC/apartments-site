# Site για τα δύο διαμερίσματα (Θεσσαλονίκη, Χαλκιδική)

Στατικό site σε [Astro](https://astro.build), όπως το Time for Wedding.
Brand: **Black Bird**. Σχέδιο: παλέτα «Πεύκο και μέλι», ζεστή εκδοχή του design kit «Πεύκο, μέλι και γκρι» (κρεμ και άμμος αντί για γκρι, πιο φρέσκο πράσινο, κοραλλί για μικρές πινελιές). Το μενού μένει πάνω-πάνω όσο σκρολάρεις.

## Πού βρίσκεται τι

| Αρχείο | Τι περιέχει | Πότε το αλλάζεις |
|---|---|---|
| `src/data/site.ts` | Όνομα, email, τηλέφωνο, οικοδεσπότης, προνόμιο απευθείας κράτησης | Στοιχεία επικοινωνίας |
| `src/data/stays.ts` | Τα δύο διαμερίσματα: κείμενα, παροχές, κανόνες, ΑΜΑ, τιμή «από», links σε Airbnb/Booking/Vrbo, booking engine. Επίσης κριτικές και οδηγοί | Ό,τι αφορά τα διαμερίσματα |
| `src/pages/index.astro` | Η αρχική | Αλλαγή διάταξης αρχικής |
| `src/pages/[slug].astro` | Η σελίδα κάθε διαμερίσματος (/thessaloniki, /chalkidiki) | Αλλαγή διάταξης διαμερίσματος |
| `src/components/` | Μενού, footer, κάρτα διαμερίσματος, πλαίσιο κράτησης | Αλλάζεις μία φορά, αλλάζει παντού |
| `src/styles/global.css` | Χρώματα, γραμματοσειρές, κουμπιά | Εμφάνιση |
| `photos/<φάκελος>/` | Οι φωτογραφίες. Μετά από κάθε νέα: `npm run images`, και το όνομα μπαίνει στο `photos` του διαμερίσματος | Νέα φωτογραφία |
| `public/img/` | Οι ελαφριές εκδοχές (WebP) που φτιάχνει το `npm run images` | Δεν τις αγγίζεις |

Ό,τι είναι σε [ΑΓΚΥΛΕΣ] είναι για συμπλήρωση. Οι γκρι περιοχές είναι θέσεις για φωτογραφίες.

## Εντολές

```
npm install        # μία φορά
npm run dev        # προεπισκόπηση στο http://localhost:4321
npm run build      # το τελικό site στον φάκελο dist/
```

## Ανέβασμα (Cloudflare Workers)

Όπως στο Time for Wedding. Ρυθμίσεις στο `wrangler.jsonc`. Στη Cloudflare:

- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`

Όνομα project στη Cloudflare: `apartments-site` (ίδιο με το `name` στο `wrangler.jsonc`).

Κάθε αλλαγή στο `main` ανεβαίνει αυτόματα.

## Εκκρεμότητες

- **Κράτηση:** μέχρι να μπει το booking engine του Hosthub, το κουμπί «Έλεγχος διαθεσιμότητας» ανοίγει email με τις ημερομηνίες συμπληρωμένες. Όταν είναι έτοιμο, μπαίνει η διεύθυνσή του στο `bookingEngineUrl` κάθε διαμερίσματος. (Το Hosthub δίνει booking engine για WordPress: πρέπει να ρωτήσουμε αν δίνει και κώδικα/σύνδεσμο για άλλο site.)
- **Κρυμμένο από τη Google:** όταν βγει κανονικά, `hideFromSearch: false` στο `src/data/site.ts` και διαγραφή του πρώτου κομματιού στο `public/_headers`.
- **Αγγλικά:** μόνο ελληνικά προς το παρόν.
- **Φωτογραφίες, χάρτης, κριτικές, άρθρα:** θέσεις χωρίς περιεχόμενο ακόμα.
- **Domain:** όταν αποφασιστεί, αλλάζει στο `astro.config.mjs` και στο `src/data/site.ts`.
